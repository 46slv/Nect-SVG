# UI文言の整理

`stop-describing-ui`をこのリポジトリの`.agents/skills/stop-describing-ui`へ導入しました。取得元は[artouc/stop-describing-ui](https://github.com/artouc/stop-describing-ui)、commitは`251a859f6e40645030e1ae69fa4b501c851eac9c`です。SKILL.mdを原文のまま保持し、MITライセンスと取得記録を添えています。外部スクリプトや依存パッケージは追加していません。

| 対象               | 変更前                                   | 変更後                                         |
| ------------------ | ---------------------------------------- | ---------------------------------------------- |
| 文書操作           | New / Open                               | New document / Open JSON                       |
| ArtworkのInspector | 操作説明の後に複製ボタン                 | 見出しの直後にDuplicate in place               |
| 複製可能な場合     | 対応グラフ、選択操作、IDや座標の説明     | Each copy above its source. One Undo.          |
| 整列               | 最終評価結果とアートボード軸の説明       | Selection bounds                               |
| ノード編集         | マーカーとハンドルの使い方を繰り返し表示 | 下流処理前の編集範囲と読み取り専用の理由を表示 |
| 空のComposition    | 何も描画しない理由と操作説明             | 既存のツール、Add node、見出しを表示           |
| 共通Inspector末尾  | ソケットと数式の説明を毎回表示           | 常時表示を削除。既存Helpと操作ガイドを参照     |

次の情報は誤操作を防ぐため残しています。

- 保存・ダウンロードの状態、未保存変更を置き換える確認、失敗の原因
- レイヤーとノードのロック、接続済み入力、未対応ルートの理由
- 全対象の複製を中止する理由、レイヤー上限、コピーを原本の直上に置く結果
- ノード編集と最終Artwork編集の違い、リサイズ時に位置と基準を固定する挙動
- 削除する対象とUndoの案内、Penの完了・破棄、ガイドの書き出し除外
- ボタンや入力のアクセシブルなラベル

スキルの「保存先などを説明しない」という一般則より、ユーザーが指定した保存状態・制約・失敗理由の保持を優先しています。すべての説明を消す運用にはしていません。通常幅と1024px幅のChrome画面を変更前後で確認し、選択・複製・Undo/Redo・中断・保存/再読込・SVG出力を既存テストで検証します。
