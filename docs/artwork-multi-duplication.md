# 複数Artworkを同じ位置へ複製

Layersの名前をクリックし、Shiftを押しながら追加のArtworkを選びます。Inspectorの「Duplicate in place」を押すと、選んだArtworkをまとめて複製します。

コピーはそれぞれの原本のすぐ上へ入ります。たとえば背面から `A / B / C` のうちAとCを選ぶと、`A / A copy / B / C / C copy` になります。選択した順番には依存しません。半透明のArtworkは同じ位置で重なるため濃く見えます。

複製後はコピー全体が選ばれ、元のアクティブArtworkに対応するコピーがアクティブになります。矢印やドラッグでコピーをまとめて移動できます。原本のノードは変わりません。Undo一回で複製前の文書・選択・アクティブArtworkに戻り、Redoで同じIDのコピーと選択が戻ります。

ロック、非表示、ガイド、未対応のグラフ、切断された余分なノード、保留中の文字調整を含む対象は複製できません。一つでも含まれる場合は全部を中止し、対象名と理由を表示します。複製後も100レイヤー以内に収まる必要があります。対応範囲は単体複製と共通です。画像と埋め込みフォントのデータは共有し、ノードやCurveのアンカーには新しいIDを割り当てます。

編集中のドラッグ、Pen、名前変更、IME変換、ダイアログが終わるまでは複製を実行できません。グラフ内の「Duplicate」は従来どおりノードの複製です。

サンプルは [artwork-multi-duplication.json](../examples/artwork-multi-duplication.json) です。Rectangle、Text、Curve、ImageをShift選択して試せます。Save JSONで保存し、Openから再編集できます。

Chromeの通常幅・小幅で検証しています。ネイティブWebView2、実際の日本語IME、ネイティブダイアログ、高DPIの動作確認は未実施です。
